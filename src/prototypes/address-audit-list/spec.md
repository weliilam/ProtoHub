# 地址审核列表

## 功能概述

地址审核管理页面，支持按条件搜索筛选、勾选批量操作，用于集中管理运单收货地址的审核状态。

## 搜索筛选项

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| YT单号 | 输入框 | 多单号以空格/逗号分隔 |
| 客户编码 | 输入框 | 模糊搜索 |
| 地址审核状态 | 下拉 | 待审核/已审核/待确认/已确认 |
| 工单号 | 输入框 | 精确搜索 |
| 订单状态 | 多选下拉 | |
| 地址类型 | 下拉 | Amazon地址/海外仓地址/私人地址 |

## 表格字段

序号、YT单号、客户编码、地址审核状态、工单号、订单状态、地址类型。

## 批量操作

- 批量审核（勾选后设置地址审核状态）
