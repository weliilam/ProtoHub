# SKU管理

> 对应业务系统：OMS / B2B（zt-portal 基础配置 `basic-config > sku-manage`）。
> 本原型使用 Proto Hub 框架（React + Ant Design）独立还原，**未复用原 Vue 业务组件**。

## 功能概述
SKU 管理用于维护「客户 + 销售产品 + 目的国家」维度的 SKU 配置，是报价、计费、履约等环节的基础数据。

- 列表查询：支持 SKU（批量）、销售产品、客户代码、目的国家、创建时间筛选
- 新增 / 编辑 SKU（字段：SKU、销售产品、客户代码、目的国家、备注）
- 批量删除（勾选后确认删除）
- 批量导入 SKU 配置（导入类型 19，支持模板下载、预览、确认导入）
- 操作日志查看（新增 / 编辑 / 删除 时间线）

## 页面字段（表格列）
序号、SKU、销售产品代码、销售产品名称、客户代码、目的国家简码、目的国家名称、
创建人、创建时间、修改人、修改时间、备注、操作（编辑）。

## 新增/编辑表单字段
| 字段 | 说明 | 校验 |
|------|------|------|
| SKU | 主键，最长 50 | 必填，编辑时不可修改 |
| 销售产品 | 关联产品代码 | 必填 |
| 客户代码 | 关联客户 | 必填 |
| 目的国家 | 国家简码 | 必填 |
| 备注 | 最长 200 | 选填 |

## 权限
- 查看列表：`oms-skumgtlist`
- 编辑/新增/删除：`skumgEdit`

## 接口（原型以本地 Mock 模拟）
- `SkuMgt/Query` 查询、`SkuMgt/AddSku` 新增、`SkuMgt/ModifySku` 编辑
- `SkuMgt/DeleteSku` 删除、`SkuMgt/GetSkuLog` 日志
- `SkuMgt/Preview` / `SkuMgt/ImportData` 批量导入预览与导入
