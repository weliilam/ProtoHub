# LBU-B2B客户单票特价申请 - 原型规格

## 功能概述

LBU-B2B客户单票特价申请原型，基于 OA 表单界面整理字段，提供完整的特价申请表单和请求接口原型。

## 页面结构

| 区域 | 说明 |
|------|------|
| 顶部主题区 | 主题标题 + 允许协同开关 |
| 基本信息 | 申请人、员工工号、申请日期、申请单号、部门 |
| 一、客户信息 | 客户代码、销售是否可以填写计费信息项 |
| 二、报价信息 | 国家、产品目录、包装规格、件数、单箱尺寸、图片、发货地址、品名、HS CODE、货物类型、报关方式、是否含锂电池、贸易方式 |
| 三、计费信息项 | 单票改价信息表格、附加费减免、价格有效期 |
| 流程处理 | 提交身份、回签方向、紧急程度、常用意见、处理意见、通知选项、附件 |
| 底部操作 | 提交、暂存、重置 |

## 交互规则

1. 红色星号字段为必填项，提交时统一校验
2. 单箱尺寸支持增删行、上下移动
3. 发货地址支持增删行、上下移动
4. 单票改价信息支持增删行
5. 当「销售是否可以填写计费信息项」选择「否」时，显示黄色提示文案
6. 当「是否存在附加费减免」选择「是」时，显示扣件减免输入项
7. 提交成功后弹出申请单号提示
