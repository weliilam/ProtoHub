# 选择交货信息弹框

## 功能概述

NUC（新用户中心）批量下单场景下，客户上传 Excel/CSV 后，系统读取第一个产品代码调 SPMS 自动匹配交货仓库。

**当前问题**：当产品代码错误或失效时，SPMS 无仓库数据返回，下拉框空、客户无感知，频繁找客服定位。

**本次优化**：在仓库下拉框为空时，**显式提示产品代码错误并提供「重新上传文件」快捷入口**，降低客服沟通成本。

对齐业务背景：批量下单流程中的"选择交货信息"环节（NUC → 批量下单 → 第二步：选择交货信息）。

## 触发场景

- 入口：批量下单页第二步「选择交货信息」按钮
- 前置：客户已上传 Excel/CSV，系统已读取并解析
- 触发：系统按文件中**第一个产品代码**向 SPMS 请求对应交货仓库

## 弹框字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 交货方式 | Radio | 是 | 云途揽收 / 客户自送；切换后仓库列表会重查 |
| 交货仓库 | Select | 是 | 由 SPMS 根据产品代码自动返回 |
| 交货时间 | DatePicker | 是 | 默认 24h 后，允许调整 |

## 异常态设计（本次新增）

### 触发条件
- 产品代码不在 SPMS 维护范围 → 仓库列表为空
- 产品代码已停用/失效 → 仓库列表为空

### 视觉规则
1. **下拉框红色边框** + 红色"*"提示必填（沿用现有规范）
2. **下拉框下方红字**显示「无数数据」（沿用现有规范）
3. **【新增】错误提示卡片**（`Alert type="error"`），位于下拉框下方，包含：
   - 标题：「未查询到仓库信息」
   - 描述：「可能是文件中的产品代码有误或该产品暂无可用仓库，请核对后重新上传」
   - 操作：「重新上传文件」链接按钮（主色 #2D7CFE），点击关闭弹框并返回批量下单第一步
4. **【新增】二级操作**：「查看正确的产品代码示例」链接，悬停显示 tooltip 说明 NUC 帮助中心链接

### 校验
- 仓库为空 + 点击「确定」：弹窗内提示「请先选择交货仓库」，确定按钮禁用直至客户重新上传文件并选择仓库

## 流程示意

```
批量下单页（第一步）
  └─ 上传 Excel/CSV（产品代码列）
       └─ 提交
            └─ 打开「选择交货信息」弹框
                 ├─ 正常态：仓库下拉有数据，正常选 → 确定 → 进入第三步
                 └─ 异常态：仓库下拉空
                      ├─ 红色错误提示卡片
                      ├─ [重新上传文件] → 关闭弹框 → 回到第一步
                      └─ [查看产品代码示例] → tooltip 提示
```

## 交互细节

- 弹框打开时自动触发仓库查询（loading 状态），loading 中下拉框 disabled
- 交货方式切换时重新触发查询
- 「重新上传文件」按钮位置：Alert 卡片内右侧，文案颜色与主操作一致，避免误以为是辅助文字
- 「确定」按钮：仓库为空时 disabled + tooltip「请先选择交货仓库」

## 与现有规范的兼容性

- 下拉框红边 + 「无数数据」红字 → 保留（向用户传达"必填未填"）
- Alert 卡片 → 增强"为什么为空"的解释，弥补现有反馈不足
- 不改动表单校验逻辑，只在原有 error 区域上方增加一层引导
