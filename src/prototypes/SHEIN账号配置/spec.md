# SHEIN账号配置

## 一、页面定位
将原 POMS 中以 JSON 配置的「商家配置」改为可视化列表管理。支持列表展示、按客户代码下拉筛选，以及新增 / 编辑 / 删除（数据本地持久化）。

## 二、数据字段（与原始 JSON 一一对应，结构保持不变）
| 字段 | 中文 | 类型 | 说明 |
| --- | --- | --- | --- |
| supplier_id | SHEIN店铺ID | number | 必填；一个店铺ID 可配置多组仓库映射（此时表中出现多行相同 supplier_id） |
| customer_code | 客户代码 | string | 如 BCNHC54308，必填 |
| customer_name | 客户名称 | string | 如 PANASIA SYNERGY LIMITED，必填 |
| shein_warehouse_id | SHEIN仓库ID | string | 如 SW100001，选填；同一店铺内唯一（跨店铺可重复） |
| warehouse_code | 仓库代码 | string | 如 W220678，必填（允许重复） |
| address | 详细地址 | string | 仓库实际地址，必填 |

> 已移除「地址代码 (address_code)」与「地址类型 (address_type)」字段。
> 数据结构保持扁平：一行 = 一个店铺ID + 一组仓库映射，无嵌套。

## 三、交互说明
1. **筛选区**：客户代码下拉筛选（选项来自列表数据）+ SHEIN店铺ID 输入框（按 supplier_id 精确匹配），两者可组合筛选；+ 重置。
2. **列表区**：分页表格，列顺序为 SHEIN店铺ID / 客户代码 / 客户名称 / 仓库代码/SHEIN仓库ID / 详细地址 / 操作。按 SHEIN店铺ID 分组，一行 = 一个店铺；「仓库代码/SHEIN仓库ID」列提供「查看」链接，点击打开只读弹窗，仅展示该店铺的仓库映射明细（仓库代码 / SHEIN仓库ID，一个店铺可有多组映射）。操作列提供「查看 / 编辑 / 删除」。
3. **新增**：弹窗表单顶部为独立的「SHEIN店铺ID」输入框（必填、全局唯一），下方为商家基础信息（客户代码 / 客户名称 / 详细地址）+ 动态「仓库映射」明细表。明细表仅「仓库代码 + SHEIN仓库ID」两列，点击「添加映射」可在一次新增中录入多组仓库映射（同一店铺多个仓库），提交后展开为多条扁平记录（共享同一 supplier_id 与基础信息）；每组行内可删除。
4. **仓库映射必填**：至少需要一组仓库映射，其中仓库代码必填（允许重复）；SHEIN仓库ID 选填，同一店铺内不可重复（跨店铺可重复）；新增 / 编辑提交时校验，若冲突则阻断并提示。
5. **编辑**：按 SHEIN店铺ID 整组编辑——弹窗预填该店铺ID 下的全部仓库映射作为明细，可增删 / 修改，提交后整体替换该店铺的映射（店铺ID 也可修改，需全局唯一）。
6. **查看**：操作列「查看」打开只读详情弹窗，展示店铺基础信息与全部仓库映射明细（编号列表）；「仓库代码/SHEIN仓库ID」列的「查看」打开只读弹窗，仅展示仓库映射明细。
7. **删除**：行内二次确认后删除该 SHEIN店铺ID 的全部映射记录（整组删除）。
8. **持久化**：数据通过 localStorage（key `pac_address_config`）持久化，刷新后保留；无数据时回退到内置示例数据。

## 四、组件库
Vue 3 + ant-design-vue，与现有原型（b2b-order-list / address-audit-list / requirement-point-record）视觉风格保持一致。
