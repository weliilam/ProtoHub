# 工单详情

## 功能概述

工单详情页面，用于查看和处理异常工单。展示工单基础信息、异常箱子明细、增值服务、工单处理记录，支持接单、放行、退回、弃件、仓库处理等操作。

## 页面结构

### 1. 工单信息（三列布局）

| 字段 | 说明 |
|------|------|
| 运单号 | 关联运单号 |
| 工单号 | 异常工单编号 |
| 目的国家 | 目的国 |
| 产品名称 | 销售产品 |
| 异常发生地名称 | 异常发生仓库/地点 |
| 监控备注 | 监控标记 |
| 资料模板 | 可下载的模板文件 |
| 客户单号 | 客户订单号 |
| 标题 | 工单标题 |
| 客户代码 | 客户编码 |
| 交仓仓库 | 交货仓库 |
| 异常发生地类型 | 海外仓/中转仓等 |
| 跟踪号 | 物流跟踪号 |
| 失败原因 | 异常原因描述 |
| 客户名称 | 客户全称 |
| 入仓时间 | 货物入仓时间 |
| 处理截止时间 | 工单处理截止时间 |
| 查验备注 | 海关/质检查验备注 |

### 2. 资料模板（Tabs 切换）

异常箱子明细、增值服务、工单记录 三个 Tab 页签在「资料模板」卡片下切换展示。

#### 异常箱子明细

| 列 | 说明 |
|----|------|
| 序号 | 行号 |
| 箱号 | 箱子编号 |
| 子单号 | 子订单号 |
| 跟踪号 | 物流跟踪号 |
| 包裹数量 | 包裹件数 |
| 重量(kg) | 箱子重量 |
| 体积(m³) | 箱子体积 |
| 长(cm) | 长度 |
| 宽(cm) | 宽度 |
| 高(cm) | 高度 |
| 异常原因 | 异常标签 |
| 处理状态 | 待处理/处理中/已完成 |

#### 增值服务

| 列 | 说明 |
|----|------|
| 序号 | 行号 |
| 增值服务 | 服务名称 |
| 增值服务生效时间 | 开始时间 |
| 增值服务结束 | 结束时间 |
| 备注 | 服务备注 |
| 操作 | 编辑/删除 |

#### 工单记录（时间线）

展示工单的完整处理记录，包括创建人、处理人、操作内容、时间等。

### 3. 底部操作按钮

- **接单**：弹窗填写处理人和备注后接单
- **放行**：选择放行原因后放行工单
- **退回**：填写退回原因后退回工单
- **弃件**：二次确认后弃件
- **仓库处理**：选择处理类型（换箱/加固包装/重新贴标/重新测量/其他）

## 技术栈

- Vue 3 + Element Plus
- @element-plus/icons-vue
