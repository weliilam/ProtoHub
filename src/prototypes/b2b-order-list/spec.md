# B2B订单列表

## 功能概述

B2B订单列表管理页面，支持多维度搜索筛选、批量操作及查看订单详情/审核。

## 搜索筛选项

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 单号 | 输入框 | 多单号以空格/逗号分隔 |
| B2B单号 | 输入框 | 多单号以空格/逗号分隔 |
| 创建时间 | 日期范围 | 精确到秒 |
| 订单类型 | 下拉 | B2B/B2C |
| 订单状态 | 多选下拉 | 已预报/已审核/已签入等 |
| 审核状态 | 下拉 | 待审核/已通过/已驳回 |
| 销售产品 | 级联 | 产品→子产品 |
| 目的国家 | 下拉搜索 | 支持二字码/名称/英文 |
| 渠道代码 | 下拉搜索 | |
| 业务员 | 下拉搜索 | 工号/姓名 |
| 客户代码 | 下拉搜索 | |
| 是否报关件 | 下拉 | 是/否 |
| 是否签名 | 下拉 | 是/否 |
| 地址类型 | 下拉 | |
| 是否扣件 | 下拉 | 是/否 |
| 是否完成增值服务 | 下拉 | 是/否 |
| 是否可配载 | 下拉 | 是/否 |
| 地址审核状态 | 下拉 | |
| 是否拦截 | 下拉 | 是/否 |
| 计费结果 | 下拉 | |
| 跟进内容 | 输入框 | 模糊搜索 |
| 是否首批 | 下拉 | 是/否 |

## 批量操作

- 批量审核
- 撤销审核
- 批量修改额外服务
- 批量修改费用
- 确认费用
- 拦截 / 取消拦截
- 删除
- **认领** — 勾选订单后认领，跟进人变更为当前登录人
- 刷新
- 复制显示列
- 列配置

## 跟进备注

- 操作列「跟进备注」按钮 → 弹窗输入跟进内容 → 提交后记录最新跟进内容
- 跟进内容支持搜索
- 确认费用
- 拦截 / 取消拦截
- 删除
- 刷新
- 复制显示列
- 列配置
