# B2B订单列表

## 功能概述

B2B订单列表管理页面，支持多维度搜索筛选、批量操作及查看订单详情/审核/日志/跟进。对齐真实业务 `repo-portal/src/views/B2B-order/B2B-order-list`。

## 表格字段（对齐真实业务主要列）

序号、运单号、订单状态、B2B单号、客户单号、创建时间、订单类型、订单来源、客户代码、是否首批、

## 批量操作

- 批量审核（需勾选）
- 撤销审核（校验：仅「已审核/已预报/已签入」且审核状态为「已通过/已驳回」可撤销，二次确认）
- 批量修改额外服务 / 批量修改费用
- 确认费用（校验：仅「已审核」状态可确认）
- 拦截（选原因+备注，A1 客户要求暂扣时备注必填）/ 取消拦截
- 删除（校验：仅「已预报」可删除，二次确认）
- 认领（勾选后跟进人变更为当前登录人，记录写入跟进历史）
- 刷新（需先输入单号/B2B单号）
- 地址审核（弹窗设置地址审核状态「待审核/已审核/待确认」，仅「已预报」可改）
- 复制显示列、列配置
- 更多菜单：8 种导出（订单详情/申报信息/计费信息/快递发票/欧洲HL发票/发货证明/签收证明/看板信息）+ 跟进记录导出 + 扣件原因导出 + 打印运单

## 跟进备注

- 操作列「跟进备注」→ 弹窗（左输入 / 右历史 Timeline），提交后写入最新跟进内容并刷新历史
- 认领操作会同步写入一条系统跟进记录

## 扣件 / 拦截

- 扣件原因列「查看」→ 弹窗展示异常编码/说明/生成与完结时间
- 拦截弹窗：拦截类型(客户原因/货物原因) + 关键词搜索 + 原因列表(单选) + 备注
