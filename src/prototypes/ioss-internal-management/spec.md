# 内部IOSS号管理

## 📋 业务与功能

### 1.1 核心目标

内部IOSS号管理页面，用于管理平台IOSS税号信息和IOSS黑名单。支持IOSS号的增删改查、导入导出、状态管理和黑名单维护。

### 1.2 功能清单

- **Tab切换**：「平台IOSS号」和「IOSS黑名单」两个 Tab 页签
- **搜索筛选**：支持按 IOSS号/IOSS识别码、平台名称、状态筛选
- **操作按钮**：新增、查询、重置
- **IOSS号脱敏展示**：保留前2后2位，中间用 * 代替
- **IOSS号列表表格**：序号、IOSS号（脱敏）、平台名称、销售产品（多个用顿号拼接，hover 展示全部）、状态、创建人、创建时间、修改人、修改时间、操作（操作日志、修改）
- **新增弹框**：填写 IOSS号、平台名称、销售产品（多选）、启用/禁用开关
- **修改弹框**：IOSS号禁用不可改，可修改平台名称和销售产品
- **操作日志弹框**：查看操作时间、操作人、操作类型、操作详情
- **黑名单Tab**：展示状态为"黑名单"的 IOSS 记录

### 1.3 交互要点

- 点击"新增"按钮 → 打开新增弹框，填写信息后确定保存
- 点击行操作"修改" → 带出当前数据，修改后保存
- 点击"导入"按钮 → 打开导入弹框，支持拖拽文件，下载模板
- 点击行操作"操作日志" → 打开日志弹框，展示该 IOSS 号的操作记录
- 点击"同步"按钮 → 从外部系统同步最新 IOSS 号数据
- IOSS识别码校验：2位大写字母 + 10位数字

## 📊 内容规划

### 2.1 信息架构

```
内部IOSS号管理
├── 页面头部（标题 + 描述）
├── Tab 页签
│   ├── 平台IOSS号
│   │   ├── 筛选栏（搜索项 + 操作按钮）
│   │   └── 数据表格
│   └── IOSS黑名单
│       ├── 筛选栏
│       └── 黑名单表格
├── 新增/修改弹框（IOSS号 + 平台名称 + 销售产品多选 + 启用开关）
└── 操作日志弹框
```

### 2.2 数据来源

- **数据类型**：IOSS 列表（`ioss_list`）
- **数据源**：用户提供（props data）/ 内置示例
- **关键字段**：
  - `ioss_code`: IOSS识别码
  - `ioss_no`: IOSS号
  - `platform_name`: 平台名称
  - `status`: 状态（active/inactive/blacklisted）
  - `creator`: 创建人
  - `create_time`: 创建时间
  - `modifier`: 修改人
  - `modify_time`: 修改时间

### 2.3 内容示例

**IOSS 示例**：IM5280000001 / IM5280000001 / Amazon / 启用 / 卓运康 / 2026-05-12 10:30:00 / 卓运康 / 2026-06-10 14:22:00
