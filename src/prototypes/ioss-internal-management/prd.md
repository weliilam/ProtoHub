# 一、需求背景

## 1.1 业务背景

为配合 Amazon 平台 IOSS 税号防盗用管控，需要在 OMS 内部建立统一的 IOSS 税号管理模块，集中管理各平台的 IOSS 税号及其与销售产品的绑定关系，同时维护 IOSS 黑名单。

## 1.2 现状问题

- 缺乏统一管理：当前 IOSS 税号分散在各业务模块中，缺乏集中的增删改查和维护入口
- 安全风险：IOSS 税号明文展示，存在泄密风险
- 关联缺失：IOSS 税号与销售产品无绑定关系，无法在下单时校验产品归属
- 黑名单缺失：无可视化的 IOSS 黑名单管理界面，不便于运营维护

## 1.3 需求目的

- 建立统一的 IOSS 税号管理页面，支持平台 IOSS 号和黑名单的集中管理
- IOSS 税号敏感信息脱敏展示，降低数据泄露风险
- 建立 IOSS 税号与销售产品的绑定关系，为下单校验提供数据基础
- 提供启用/禁用功能，灵活控制 IOSS 税号的可用状态

# 二、业务价值

## 2.1 项目价值

- 风险/合规指标：IOSS 税号脱敏展示，防止敏感数据泄露；建立税号-产品绑定，从源头杜绝盗用
- 提效指标：集中化管理替代分散维护，运营人员无需跨模块操作

## 2.2 其他价值

- 客户价值：保障合法 IOSS 税号持有者的数据安全，维护平台信任
- 战略贡献：补齐 IOSS 税号管理短板，支撑全链路合规管控体系

# 三、业务场景

- **新增 IOSS 税号**：内部用户（运营/客服）新增平台 IOSS 税号并绑定销售产品，需填写 IOSS 号、选择平台、选择销售产品（多选）
- **修改 IOSS 税号**：内部用户（运营/客服）修改已有 IOSS 税号的平台或销售产品，IOSS 号不可修改，仅可改平台名称和销售产品
- **启用/禁用**：内部用户（运营/客服）启用或禁用某个 IOSS 税号，列表提供启用/禁用按钮
- **查询 IOSS 税号**：内部用户（运营/客服）按 IOSS 号、平台名称、状态筛选查询
- **操作日志**：内部用户（运营/客服）点击操作日志按钮查看历史操作记录
- **黑名单查看**：内部用户（运营/客服）切换到黑名单 Tab 查看被拉黑的 IOSS 税号

# 六、功能清单

## 6.1 功能明细

- **查询 IOSS 号**（OMS > 内部IOSS号管理 > 平台IOSS号）：按 IOSS 号、平台名称、状态筛选查询
- **新增 IOSS 号**（OMS > 内部IOSS号管理 > 平台IOSS号）：填写 IOSS 号、选择平台和销售产品
- **修改 IOSS 号**（OMS > 内部IOSS号管理 > 平台IOSS号）：修改平台名称和绑定销售产品，IOSS 号不可改
- **启用/禁用 IOSS 号**（OMS > 内部IOSS号管理 > 平台IOSS号）：控制 IOSS 税号的可用状态
- **IOSS 号脱敏展示**（OMS > 内部IOSS号管理 > 平台IOSS号）：列表和修改弹框中 IOSS 号保留前2后2，中间用 * 代替
- **销售产品展示**（OMS > 内部IOSS号管理 > 平台IOSS号）：列表展示绑定的销售产品，多个用顿号拼接，hover 展示全部
- **操作日志**（OMS > 内部IOSS号管理 > 平台IOSS号）：查看单个 IOSS 号的操作历史
- **黑名单查看**（OMS > 内部IOSS号管理 > IOSS黑名单）：单独 Tab 展示黑名单 IOSS 号，支持筛选查询

# 七、功能描述

## 7.1 查询 IOSS 号

- **描述**：在搜索栏输入/选择筛选条件后，列表展示符合条件的 IOSS 号记录。IOSS 号以脱敏形式展示（保留前2后2位），销售产品多个用顿号拼接，hover 显示全部
- **字段**：IOSS 号（脱敏）、平台名称、销售产品、状态、创建人、创建时间、修改人、修改时间
- **规则**：搜索条件中 IOSS 号模糊匹配、平台名称精确匹配、状态精确匹配；IOSS 号脱敏规则为保留前2位和后2位，中间用 * 填充；销售产品超出列宽时省略，hover Tooltip 展示全部

## 7.2 新增 IOSS 号

- **描述**：点击"新增"按钮打开弹框，填写 IOSS 号、选择平台名称、选择销售产品（多选），确定后保存
- **字段**：IOSS 号（必填）、平台名称（必选）、销售产品（必选，多选）
- **规则**：IOSS 号必填不可为空；平台名称从配置中下拉选择；销售产品支持多选，支持搜索过滤；保存后关闭弹框并刷新列表

## 7.3 修改 IOSS 号

- **描述**：点击行操作"修改"打开弹框，IOSS 号以脱敏形式展示且不可编辑，可修改平台名称和销售产品
- **字段**：IOSS 号（脱敏展示，禁用不可改）、平台名称（可改）、销售产品（可改，多选）
- **规则**：IOSS 号禁止修改，输入框置灰；平台名称和销售产品可修改

## 7.4 启用/禁用 IOSS 号

- **描述**：在操作栏点击"启用"或"禁用"按钮，对选中的 IOSS 号进行批量状态切换
- **字段**：状态（启用 → 停用，或停用 → 启用）
- **规则**：启用操作将状态改为 active；禁用操作将状态改为 inactive；黑名单状态的 IOSS 号不可使用启用/禁用

## 7.5 操作日志

- **描述**：点击行操作"操作日志"按钮，弹框展示该 IOSS 号的历史操作记录
- **字段**：操作时间、操作人、操作类型、操作详情
- **规则**：按操作时间倒序展示

## 7.6 IOSS 黑名单查看

- **描述**：切换到"IOSS黑名单"Tab，展示所有状态为"黑名单"的 IOSS 号记录，支持按 IOSS 号和平台名称筛选
- **字段**：同平台IOSS号列表字段
- **规则**：仅展示状态为 blacklisted 的记录

# 八、验证标准

## 8.1 验收场景

- **新增 IOSS 号**：点击新增，输入 IOSS 号、选择平台和销售产品，确定保存 → 弹框关闭，列表刷新，新增记录出现在列表第一页
- **新增必填校验**：新增弹框中 IOSS 号留空，直接确定 → 提示"请输入IOSS号"
- **修改 IOSS 号**：点击某行修改，弹框中 IOSS 号脱敏且不可编辑，修改平台名称和销售产品后确定 → 列表对应行数据更新
- **启用/禁用**：选中某条启用状态的记录，点击禁用 → 该记录状态变为停用
- **IOSS 号脱敏**：查看列表和修改弹框中的 IOSS 号 → 显示为前2位+星号+后2位（如 `IM******01`）
- **销售产品 hover**：鼠标移入有多条销售产品的记录 → Tooltip 展示全部销售产品名称
- **条件查询**：选择平台名称 Amazon，点击查询 → 列表仅展示 Amazon 平台的记录
- **黑名单 Tab**：切换到 IOSS 黑名单 Tab → 列表仅展示状态为"黑名单"的记录

## 8.2 造数需求

- **IOSS 号**：有效的 IOSS 号（如 IM5280000001）→ 用于新增和列表展示，至少准备 8 条
- **销售产品**：已创建的销售产品数据 → 用于新增/修改时选择绑定，覆盖多平台
- **黑名单记录**：状态设为 blacklisted 的 IOSS 记录 → 用于黑名单 Tab 展示，至少 1 条

# 九、非功能需求

## 多语言

需要支持多语言（默认中英文）

## 多时区

需要支持多时区

## 安全合规

- IOSS 号（限制字段）：保留前2后2，中间用 * 代替

## 权限

- 菜单权限：内部IOSS号管理 → 是
- 按钮权限：新增 IOSS 号 → 是
- 按钮权限：修改 IOSS 号 → 是
- 按钮权限：启用/禁用 → 是

## 性能

- 列表查询：可用率 99.99%，响应时间 < 1s，并发量 >50
- 新增/修改操作：可用率 99.99%，响应时间 < 500ms，并发量 >20

## 浏览器兼容性

- 兼容 Windows 的谷歌、火狐；Mac 系统的谷歌、火狐、Safari
- 分辨率：自适应 1440~1920 和小于 1440，固定到 1440，出现横向滚动条
