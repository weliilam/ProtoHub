# DW送达时段列表

## 功能概述

DW（送达时间窗口）送达时段列表管理页面，TMS运营人员查看和管理FBA货件的送达时段信息，支持修改、获取送达时间、批量修改、批量导入及查看操作日志。

## 表格字段

| 列名 | 说明 | 筛选 |
|------|------|------|
| YT单号 | 云途内部单号，等宽字体 | 输入搜索 |
| 主箱号 | FBA货件ID，支持多箱，等宽字体 | 输入搜索 |
| 客户代码 | 客户编码，含授权Tag | - |
| 仓点 | 仓库名称（美西仓/美东仓/欧洲仓等） | 输入搜索 |
| 区域分布 | 区域（北美/欧洲/亚太） | 输入搜索 |
| 预计送达时段 | 预计送达的时间窗口 | 输入搜索 |
| 状态 | 可修改/不可修改/未知 | 下拉筛选 |
| 剩余天数 | 距离宽限期截止天数，分色显示 | - |
| 宽限期限 | 最新送达时段开始日期 | - |
| 客户送达时段 | 客户下单时填写的送达窗口 | - |
| 最新送达时段 | 最近一次获取或修改后的送达时段 | - |
| 实际约仓日期 | 实际确认的约仓日期 | 日期范围 |
| 预计约仓日期 | 约仓日期 | 日期范围 |
| 约仓录入时间 | 约仓录入时间戳 | - |
| 创建时间 | 记录创建时间 | 日期范围 |
| 修改时间 | 最近修改时间 | - |
| 操作 | 修改 / 重新获取 / 日志 | - |

## 操作

- **修改送达时段**：无需客户端校验，直接选择新时段，由接口返回结果判断
- **批量修改**：勾选多条记录后统一修改预计送达时段
- **批量导入**：通过文件导入数据批量更新
- **重新获取送达时间**：调用POMS获取最新DW数据并刷新列表
- **日志**：查看过程数据，含操作时间、操作人、操作前数据、操作结果
